## 📌 Definition of Done (MVP)
- [ ] JPG/PNG/PDF принимаются, ошибочные файлы отклоняются с ясной причиной.
- [ ] OCR отрабатывает минимум на трёх типах документов из набора организаторов.
- [ ] Для каждого поля возвращаются `value`, `status`, а при наличии — `confidence` и `bbox`.
- [ ] Проверка возвращает реальные `rule_id` и текст нормы только из официального Положения.
- [ ] Нет выдуманных полей и ссылок на несуществующие пункты.
- [ ] При низком OCR-confidence ответ помечается как требующий ручной проверки.
- [ ] JSON на закрытых примерах соответствует официальной схеме.
- [ ] Запуск на машине без GPU и без внешних LLM API воспроизводим.
- [ ] Есть README по запуску, короткое видео, презентация (ограничения перепроверить).

## 🔎 Критерии проверки
Точность полей (по каждому типу), корректность ссылок, доля необоснованных решений, время выполнения на CPU, устойчивость на шумных фото, полезность интерфейса.

См. [[06 Качество/План тестирования]].

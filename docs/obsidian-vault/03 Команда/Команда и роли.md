## 📌 Кто отвечает за результаты
- Датасет и официальный формат `results.json`: **Игорь** (Кирилл реализует экспорт).
- API-контракт: **Кирилл + Арсений**, утверждает Игорь.
- Интерфейс и демонстрация: **Арсений**.
- Автоматические проверки: **Кирилл**, E2E — Арсений.
- Документация и сдача: **Игорь**, все помогают с видео.

## 🔎 Правила взаимодействия
1. Ежедневный 15-минутный синк: сделано / сегодня / блокеры.
2. PR меньше 300–500 строк по возможности, хотя бы один reviewer.
3. Никогда не менять API-контракт молча; сначала согласование.
4. До 14 октября добиться сквозного сценария даже без LLM.

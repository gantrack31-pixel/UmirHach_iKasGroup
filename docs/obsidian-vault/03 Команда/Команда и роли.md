# Команда и роли

## Рабочее распределение

| Участник | Основная зона | Что сейчас важно |
|---|---|---|
| Кирилл | Backend/OCR | EasyOCR, извлечение полей, API, тесты, ограничения файлов |
| Арсений | Frontend/UI | Основной экран, страница `/help`, адаптив, интеграция API |
| Игорь | Fullstack/интеграция | Контракт, правила Положения, сдача, документация, PR |

## Кто отвечает за результаты

- API-контракт: Кирилл + Арсений, финально сверяет Игорь.
- OCR-качество и ограничения: Кирилл.
- UX проверки и справочник: Арсений.
- Нормативная проверка и `results.json`: Игорь.
- Документация и презентация: Игорь, с входными данными от всех.

## Правила взаимодействия

1. Любое изменение контракта `/analyze` сразу фиксировать в [[02 Техника/Контракт API]].
2. UI не должен обещать юридическое решение, пока нет слоя правил.
3. OCR-ошибки фиксировать как кейсы, а не чинить подстановкой известных значений.
4. Перед merge показывать ручной сценарий: загрузка файла → вопрос → результат.

## 📌 Ветки
`main` — стабильная демо-версия; `dev` — интеграция (опционально); `feat/ocr-pipeline`, `feat/upload-ui`, `fix/rule-citation` — рабочие ветки.

## 🔎 Рабочий цикл
```bash
git checkout main
git pull --ff-only
git checkout -b feat/ocr-pipeline
# изменения + тесты
git add .
git commit -m "feat(ocr): add Russian document pipeline"
git push -u origin feat/ocr-pipeline
```
Создавать Pull Request → проверка тестов → ревью → merge. Не работать всем в `main` одновременно.

## Соглашения
`feat`, `fix`, `docs`, `test`, `refactor`, `chore`. В описании PR: что сделано, как проверено, скриншот UI (если есть), ломается ли API.

## Безопасность
`.env`, ключи, студенческие документы, модели и крупные датасеты не коммитить. `.env.example` — без секретов. Проверьте лицензию набора и условия распространения. Добавьте `.gitignore` для `__pycache__`, `node_modules`, `.venv`, `data/private`, `models`.

## Перед merge
- [ ] Тесты прошли.
- [ ] Новые API-изменения отражены в [[02 Техника/Контракт API]].
- [ ] Нет ключей и приватных файлов.
- [ ] Проверен ручной сквозной сценарий.

## 📌 Набор тестов
| Сценарий | Ожидаемое поведение | Уровень |
|---|---|---|
| JPG/PNG/PDF хорошего качества | Распознаёт и возвращает поля | API + интеграция |
| Повернутое/смазанное изображение | Предобработка или запрос ручной проверки | OCR |
| Пустой / битый PDF | Безопасная ошибка, не 500 | API |
| Несколько дат | Возвращает неоднозначность, не придумывает | unit |
| Подпись/печать только как слова | Не помечает автоматически как подтверждённые | unit |
| Поле не найдено | `not_detected`, без ложного `missing` | unit |
| Неизвестный пункт Положения | Запретить цитирование | unit |
| Неизвестный тип | Объяснение/ручная проверка | интеграция |
| Отключённая LLM | Шаблонный ответ работает | интеграция |
| Нет интернета | Генерация работает без внешних LLM API | e2e |
| JSON экспорта | Полное соответствие официальной схеме | schema |

## 🔎 Измерения
- OCR: CER/WER при наличии эталонного текста.
- Поля: precision / recall / F1 **по каждому реквизиту** и типу документа.
- Ссылки: доля цитат, реально существующих в Положении.
- Инференс: медиана/95-й перцентиль времени на CPU на фиксированном устройстве.
- Reliability: доля безопасных отказов на низкокачественных входах.

## Тестовые данные
Используйте синтетические документы организаторов и отдельную локальную папку фикстур. Не загружайте приватные документы в публичный GitHub. Проверьте лицензию датасета.

## Команды (пример после создания проекта)
```bash
cd backend
pytest -q
```
```bash
cd frontend
npm run build
```

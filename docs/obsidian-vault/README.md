# Онлайн-деканат — Obsidian Vault

Это рабочая документация проекта. Открывайте папку `docs/obsidian-vault` в Obsidian через **Open folder as vault / Открыть папку как хранилище**.

## Как пользоваться

1. Начните с [[00 Главная]].
2. Технические решения смотрите в разделе [[02 Техника/Архитектура]].
3. Текущие задачи ведутся в [[04 Задачи/Главный TODO]].
4. Проверки и риски фиксируются в [[06 Качество/План тестирования]] и [[06 Качество/Риски и запасные решения]].

## Что считается источником истины

- Реальный код в `frontend/` и `backend/online-dekanat-backend/`.
- README backend: `backend/online-dekanat-backend/README.md`.
- Официальные материалы организаторов, если они противоречат этим заметкам.

## Что не хранить в vault

- Реальные документы студентов.
- OCR-модели и веса.
- `.env`, токены, ключи, приватные датасеты.
- Большие бинарные файлы, кроме небольших иллюстраций/скриншотов, которые нужны для документации.

## Текущее важное замечание

Ветка `feature/help-card` уже отправлена на GitHub и открыла PR `#6`. В рабочем дереве при этом есть другие незакоммиченные изменения backend/OCR, которые не относятся к help-странице. Перед новым PR проверяйте `git status`.

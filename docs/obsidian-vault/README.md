# 🧭 Онлайн-деканат — Obsidian Vault

> [!abstract] Кратко
> Страница рабочей документации проекта «Онлайн-деканат». Исходное содержание сохранено.


Это **планирование и документация**, не исходный код приложения. В клоне репозитория откройте в Obsidian папку `docs/obsidian-vault` через **Open folder as vault / Открыть папку как хранилище**. Для обмена изменениями используйте общий GitHub-репозиторий: сначала `git pull`, после работы — commit и `git push`. Начните с [[00 Главная]].

Структура поддерживается **стандартным Obsidian без плагинов**. Отметки задач — обычные Markdown checkbox; шаблоны можно подключить встроенным плагином Templates (`Settings → Core plugins → Templates`, folder `09 Шаблоны`). Встроенные ежедневные заметки при желании настраиваются отдельно. Дата старта 2026-10-10; дедлайн в примере 2026-10-16, **уточнить реальное время сдачи**.

Важное: имена назначены ролям **по порядку**, требуется подтверждение команды. Задачи, критерии оценки и JSON в vault — рабочие проекты; спецификация организаторов имеет приоритет.

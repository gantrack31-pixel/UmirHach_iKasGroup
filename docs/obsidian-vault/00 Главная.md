## Рабочие правила
- Источник истины — **выданные организаторами** README, Положение и эталонные файлы, а не примеры в этом хранилище.
- Статусы TODO меняются вручную: `- [ ]` → `- [x]`; никто не должен считать файл автоматически актуальным.
- Не использовать реальные персональные данные студентов; демонстрации — только на синтетических примерах.
- Ссылки на пункты Положения берём из проверенной базы, а не генерируем свободно.

> [!NOTE] Допущение о распределении ролей
> Имена распределены **в порядке сообщения**: Кирилл = Backend, Арсений = Frontend, Игорь = Fullstack. Если в команде иначе, исправьте [[03 Команда/Команда и роли]] и задачи.

## Как работать
1. Сначала прочитать [[01 Проект/Паспорт проекта]] и [[07 Материалы/Работа с датасетом]].
2. На каждый день открыть соответствующий файл из [[05 Календарь/Календарь спринта]].
3. Задачи отмечать в [[04 Задачи/Главный TODO]], блокеры — в [[06 Качество/Риски и запасные решения]].
4. В конце дня заполнять [[09 Шаблоны/Шаблон ежедневного отчёта]].

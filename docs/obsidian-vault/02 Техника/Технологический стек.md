## 📌 Основной стек (решение для старта)
| Слой           | Выбор                                          | Зачем                                   |
| -------------- | ---------------------------------------------- | --------------------------------------- |
| UI             | React + Vite + TypeScript                      | Быстрый понятный интерфейс              |
| API            | FastAPI + Pydantic                             | Проверка схем, OpenAPI, async-эндпоинты |
| OCR            | PaddleOCR, русскоязычная конфигурация PP-OCRv5 | Распознавание и координаты текста; CPU  |
| PDF            | PyMuPDF                                        | Текст PDF; растеризация сканов          |
| Предобработка  | OpenCV + Pillow                                | Поворот, контраст, размер               |
| Парсинг        | Python, regex, Pydantic                        | Нормализация ФИО, дат, номеров          |
| Поиск норм     | Структурированный JSON + SQLite FTS5           | Точные ссылки на положения              |
| Доп. генерация | Qwen3-1.7B-GGUF через llama.cpp                | Необязательный объяснитель на CPU       |
| Сборка         | Docker Compose + `.env.example`                | Воспроизводимость                       |
| Тесты          | pytest + Playwright (smoke)                    | Контроль регрессий                      |

## 🔎 Альтернативы (при проблемах)
| Проблема | Замена / действие |
|---|---|
| PaddleOCR слишком тяжёлый | RapidOCR + ONNX Runtime; проверить качество на русском |
| OCR не читает фото | deskew, grayscale, CLAHE, ресайз; сравнить результат до/после |
| LLM медленная | Полностью отключить и использовать шаблонные ответы |
| Qwen3-1.7B слаба | Qwen3-4B Q4 при достаточной RAM; измерить задержку |
| RAM мало | Qwen3-0.6B или обойтись вообще без LLM |
| SQLite FTS недостаточен | Поиск по ID/тегам, ручная таблица пунктов; векторный RAG не обязателен |
| CPU критически медленный | Понизить разрешение OCR, ограничить страницы, очередь задач, кэш |

## Память/производительность
Q4 модели занимают ориентировочно: Qwen3-1.7B около 1–1.5 ГБ веса; фактическая RAM больше и зависит от контекста. Целевой ориентир — 8–16 ГБ RAM, но **замерьте на реальном железе**. Для OCR требуется отдельная память.

## Важные настройки
- Все модели скачиваются заранее; запросы инференса только на `localhost`.
- Запрет исходящих запросов к внешним LLM API — архитектурное правило.
- Не отправляйте документы в телеметрию/облачные логи.
- Явно фиксируйте версии пакетов и хеши моделей.

## 📌 Что запросить/проверить в первую очередь
- [ ] README архива, разрешённые лицензии и ограничения на использование.
- [ ] Входные документы, названия трёх классов.
- [ ] Официальный перечень обязательных полей каждого типа.
- [ ] Файл Положения, версия, номера пунктов и машиночитаемые ссылки.
- [ ] Эталонные ответы и пример `results.json`.
- [ ] Правило обработки отсутствующих/нечитаемых данных.
- [ ] Точные требования к CPU, допустимым моделям и времени ответа.

## 🔎 Протокол изучения
1. Создать локальную папку `data/private` вне Git (не часть этого vault).
2. Изучить 10 документов каждого типа (если доступны).
3. Выписать обязательные поля и варианты оформления.
4. Выделить минимум 10 плохих изображений и неизвестных полей.
5. Определить ground truth и метрику, вести экспериментальный журнал.
6. Только после этого закрепить JSON-схему экспорта и значения rule_id.

## Шаблон таблицы полей

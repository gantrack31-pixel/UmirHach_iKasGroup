# Полезные материалы

## Документация по текущему стеку

- [FastAPI](https://fastapi.tiangolo.com/) — API, forms, files, OpenAPI.
- [Pydantic](https://docs.pydantic.dev/latest/) — модели ответов.
- [EasyOCR GitHub](https://github.com/JaidedAI/EasyOCR) — локальный OCR.
- [PyMuPDF](https://pymupdf.readthedocs.io/) — рендер PDF.
- [Pillow](https://pillow.readthedocs.io/) — изображения.
- [OpenCV](https://docs.opencv.org/) — обработка пикселей подписи/печати.
- [pytest](https://docs.pytest.org/) — backend tests.
- [React](https://react.dev/learn) — UI.
- [Vite](https://vite.dev/guide/) — dev/build.
- [Sass](https://sass-lang.com/documentation/) — SCSS.
- [Obsidian links](https://help.obsidian.md/links) — wikilinks.

## Запасные технологии

- RapidOCR/ONNX — если EasyOCR слишком тяжёлый.
- PaddleOCR — исторически рассматривался, но сейчас не активный стек.
- Demo service frontend — запасной режим UI без backend.

## Что не использовать без разрешения

- Внешние LLM API.
- Внешние OCR API.
- Реальные документы студентов в публичных репозиториях.
- Генерацию ссылок на Положение без валидатора.

## 📌 Официальная документация
- [Obsidian: внутренние ссылки](https://obsidian.md/help/links) — синтаксис wikilinks, перекрёстная навигация.
- [Obsidian: свойства YAML](https://obsidian.md/help/properties) — статусы, даты, теги.
- [FastAPI](https://fastapi.tiangolo.com/) — API и OpenAPI.
- [Pydantic](https://docs.pydantic.dev/latest/) — модели и валидация.
- [React](https://react.dev/learn) — интерфейс.
- [Vite](https://vite.dev/guide/) — сборка фронтенда.
- [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite) — стили.
- [PaddleOCR](https://www.paddleocr.ai/) и [GitHub PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) — OCR и языковые пакеты (проверьте поддержку русского у выбранной конфигурации).
- [RapidOCR](https://github.com/RapidAI/RapidOCR) — OCR на ONNX как альтернатива.
- [PyMuPDF](https://pymupdf.readthedocs.io/) — PDF.
- [OpenCV](https://docs.opencv.org/) — обработка изображений.
- [SQLite FTS5](https://www.sqlite.org/fts5.html) — полнотекстовый поиск.
- [Qwen3-1.7B GGUF](https://huggingface.co/Qwen/Qwen3-1.7B-GGUF) — официальный GGUF репозиторий.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) — локальный CPU-инференс.
- [Ollama](https://docs.ollama.com/) — удобный быстрый прототип.
- [pytest](https://docs.pytest.org/) — тестирование Python.
- [Playwright](https://playwright.dev/docs/intro) — UI smoke.
- [Docker Compose](https://docs.docker.com/compose/) — локальная оркестрация.

## 🔎 Примеры экспериментов
1. На 10–30 страницах документов замерить ошибки OCR, сравнить PaddleOCR и RapidOCR.
2. Сформировать для каждого типа матрицу полей (обязательные/необязательные/визуальные).
3. Сопоставить вопросы с конкретными ID норм; проверить, что все ссылки существуют.
4. Сравнить формулировку шаблоном и локальной Qwen3 по точности и задержке.

## Что не использовать
- Внешние API языковых моделей, даже «бесплатные».
- Внешние OCR-сервисы до письменной проверки регламента и политики данных.
- Реальные студенческие документы в публичных примерах.

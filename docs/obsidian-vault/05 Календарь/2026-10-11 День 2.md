### 👤 Задачи по исполнителям

#### Кирилл — Backend

- [ ] **2.1 Подключить OCR** — Сделать конвертацию страниц PDF PyMuPDF→изображение; PaddleOCR ru для JPG/PNG.
  - **Критерий готовности:** На тестовых файлах возвращаются text, bbox, confidence. **Артефакт:** OCR pipeline.
- [ ] **2.2 Ограничить и логировать** — Лимиты страниц, времени и размера; обработка битых файлов; обезличенные логи.
  - **Критерий готовности:** Тест плохого PDF и таймаута. **Артефакт:** Предсказуемые ошибки.

#### Арсений — Frontend

- [ ] **2.1 Завершить загрузчик** — Drag-and-drop, выбор файла, формат/размер, прогресс ожидания.
  - **Критерий готовности:** Демонстрация валидного и ошибочного файла. **Артефакт:** Готовый UI загрузки.
- [ ] **2.2 Сделать OCR-предпросмотр** — Экран текста OCR, состояния loading/empty/error, повторная попытка.
  - **Критерий готовности:** Показать результат мок/живой API. **Артефакт:** Пользователь понимает состояние.

#### Игорь — Fullstack

- [ ] **2.1 Определить Pydantic-схемы** — Модели всех 3 типов, unknown/null, confidence, координаты и status.
  - **Критерий готовности:** Схемы проходят сериализацию и тесты. **Артефакт:** Единый контракт.
- [ ] **2.2 Собрать фикстуры** — Минимум 3 типовых и 3 дефектных документа/примера; контроль ожидаемых полей.
  - **Критерий готовности:** Тестовый набор хранится без реальных персональных данных. **Артефакт:** Контроль качества OCR.

### 🚧 Если возникли проблемы

> [!warning] Приоритеты
> Сначала восстановить цепочку «файл → OCR → поля → правила → результат», затем улучшать интерфейс и локальную LLM. Если датасет или формат экспорта не выданы, работать на синтетических фикстурах, явно пометив их предварительными.

- [ ] Если работа остановлена более чем на один рабочий блок — записать блокер и назначить помощника.
- [ ] Если интеграция сломалась — вернуться к последнему рабочему сценарию и использовать моки/фолбэк.
- [ ] Если CPU-модель слишком медленная — отключить LLM и сохранить детерминированные ответы.

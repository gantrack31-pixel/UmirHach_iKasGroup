### 👤 Задачи по исполнителям

#### Кирилл — Backend

- [ ] **1.1 Настроить Python venv, FastAPI и /health** — Создать backend/, зависимости и команду запуска; добавить /health с кодом 200.
  - **Критерий готовности:** Проверить curl /health, сохранить скрин/лог. **Артефакт:** Контракт запуска сервера и базовый pytest.
- [ ] **1.2 Создать безопасную загрузку** — POST /api/documents/upload: JPG/PNG/PDF, размер из конфига, временное хранение.
  - **Критерий готовности:** Тест валидного/невалидного MIME и пустого файла. **Артефакт:** Файл доступен только для локальной обработки.

#### Арсений — Frontend

- [ ] **1.1 Собрать Vite + React + TS** — Создать маршруты загрузки/результата и единые UI-состояния.
  - **Критерий готовности:** npm run dev и сборка без ошибок. **Артефакт:** Стартовый интерфейс.
- [ ] **1.2 Согласовать API-моки** — Сделать типы UploadResponse и AnalysisResponse; демонстрацию с фикстурами.
  - **Критерий готовности:** Страница работает без сервера. **Артефакт:** Демо UX для команды.

#### Игорь — Fullstack

- [ ] **1.1 Разобрать датасет и правила** — Проверить README, Положение, синтетические примеры, структуру results.json; составить карту обязательных полей.
  - **Критерий готовности:** Список открытых вопросов и таблица полей по 3 типам. **Артефакт:** Базовые спецификации.
- [ ] **1.2 Согласовать интеграцию** — Создать ветки/PR-правила; зафиксировать маршруты и формат ошибок, задачу первичного smoke.
  - **Критерий готовности:** Все участники подтвердили API-контракт. **Артефакт:** Нет расхождения имен JSON-полей.

### 🚧 Если возникли проблемы

> [!warning] Приоритеты
> Сначала восстановить цепочку «файл → OCR → поля → правила → результат», затем улучшать интерфейс и локальную LLM. Если датасет или формат экспорта не выданы, работать на синтетических фикстурах, явно пометив их предварительными.

- [ ] Если работа остановлена более чем на один рабочий блок — записать блокер и назначить помощника.
- [ ] Если интеграция сломалась — вернуться к последнему рабочему сценарию и использовать моки/фолбэк.
- [ ] Если CPU-модель слишком медленная — отключить LLM и сохранить детерминированные ответы.

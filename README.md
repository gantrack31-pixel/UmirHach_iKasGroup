# Онлайн-деканат — каркас проекта

Стартовая заготовка для командной разработки прототипа проверки студенческих документов. Здесь намеренно оставлены TODO: OCR, правила Положения, распознавание полей и генерация ответов ещё не реализованы.

## Структура

- `backend/` — API, схемы и будущие модули обработки документов.
- `frontend/` — интерфейс React + TypeScript.
- `data/` — место для правил и обезличенных тестовых фикстур.
- `docs/obsidian-vault/` — общая документация проекта в формате Obsidian.
- `docker-compose.yml` — локальная заготовка запуска сервисов.

## Локальный запуск для разработки

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Заготовка API: `http://localhost:8000`; документация FastAPI: `http://localhost:8000/docs`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Работа команды

1. Перед реализацией сверяйте поля документов, пункты правил и экспорт с материалами организаторов.
2. Не добавляйте в репозиторий реальные персональные данные студентов или загруженные документы.
3. `data/rules/` пока содержит только заглушку: не подменяйте ею официальное Положение.
4. Согласуйте изменения API-контракта между frontend и backend.
5. Для задач используйте TODO в соответствующем модуле; удаляйте заглушки по мере реализации.

## Общее хранилище Obsidian

Документация находится в `docs/obsidian-vault/`. Чтобы открыть её, выберите в Obsidian **Open folder as vault / Открыть папку как хранилище** и укажите эту папку внутри клона репозитория.

Изменения заметок распространяются через GitHub: перед работой получите актуальные изменения (`git pull`), после правок создайте коммит и отправьте его (`git push`). Перед отправкой снова подтяните изменения команды и разрешите конфликты, если они возникли. Это не мгновенная синхронизация; не редактируйте одну и ту же заметку одновременно без координации.

Общие настройки плагинов Obsidian хранятся в `.obsidian/`. Файл `workspace.json` с локальным состоянием окон не публикуется.
